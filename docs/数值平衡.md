# 数值平衡模型（Skill Balance）

> 目标：所有技能落在**同一性价比曲线**上；新增角色只填规格，威力**自动求解**，不会数值崩盘。
> 实现：`js/balance.js`（模型）+ `js/costumes.js`（专属招式规格表）+ `scripts/balance-check.js`（校验）。

## 核心公式
```
预算 budget(sp) = BASE(0.85) + SP_VALUE(0.60) × sp
技能价值 value  = 按 目标范围 × 附带效果 折算
平衡分 score    = value / budget   ≈ 1.00 即达标（|偏差| < 0.18）
```
威力不手填，由 `Balance.idealPower(规格)` 反解，使 score=1。

## 折算系数（`js/balance.js` 顶部可调）
- 目标范围 TF：单体 1.0 / 整排 1.75 / 全体 2.1 / 全体友方 2.1
- 治疗 ×0.85、护盾 ×0.90、增益 ×1.10
- 灼烧/中毒：每跳威力 × 回合 × 0.55
- 眩晕 0.80/回合、沉默 0.30/回合、破防 ×1.20、击退 0.20/目标、穿透 0.15、嘲讽 0.60

## 新增角色技能的流程
1. 在 `js/costumes.js` 的 `SIG_SPECS` 加一条规格（name/target/effect/sp/icon + 附带效果），**不写 power**。
2. 在 `BASE_SIG` 把该角色初始服装指向这个技能。
3. 跑 `node scripts/balance-check.js`：确认新技能 score≈1.00、无 ⚠超标。
4. 跑 `node scripts/combat-test.js`：确认实战能释放、无异常。

> 想整体调强/调弱：只改 `balance.js` 的 `SP_VALUE` 或 `TF` 一个常数，全体技能同步重算，不会顾此失彼。
