# 美术圣经 · Art Bible
### 棕色尘埃2 风格克隆 — 全局美术规范（v1.0）

> 本文件是**全项目美术的唯一权威**。所有立绘、精灵、场景、UI、CG、特效都必须遵守本规范。
> 一句话定调：**赛璐璐（Cel-shading）日式动画风 + HD-2D 表现 + DragonBones 2D 骨骼动画**，
> 全局风格、配色、线条、光影、比例必须**完全一致**。
> 北极星参考：**《棕色尘埃2》（Brown Dust 2）**——"会动的插画"。

---

## 0. 核心理念（Design Pillars）

1. **一致性 > 单点惊艳**：宁可整体统一也不要某一张特别炸、其余割裂。一切以"放在一起不违和"为最高准则。
2. **赛璐璐唯一风格**：禁止厚涂、写实、像素、3D-PBR、扁平 flat、像素描边等任何其它画风混入。
3. **同源原则**：战斗单位 = 立绘本体（同一套骨骼动画），不另画一套小人，保证立绘和战斗视觉是同一个角色。
4. **角色动画统一用 DragonBones**：待机/走/跑/普攻/技能/大招/受击/胜利全部走同一套骨架与命名规范。
5. **角色必须"融入"场景**：靠**边缘光（rim light）+ 接地阴影 + 色调统一**解决"立绘贴在场景上很违和"的老问题。

## 1. 风格基准（Style Foundation）

### 1.1 线条（Line Art）
- **闭合干净线**，矢量感，无毛边、无断线。
- **线宽层级**：外轮廓最粗 → 结构线中等 → 内部细节最细（约 3:2:1）。
- **色线（色トレス）**：皮肤、头发、布料的部分内线用"固有色的暗版"代替纯黑，柔化生硬感；纯黑线仅用于强硬轮廓。
- 线条颜色**永不纯黑 #000**，最深用 `#241a2e`（带紫的深褐），与全局暗色调统一。

### 1.2 上色（Cel Shading）
- **2 阶为主、3 阶为限**：固有色（base）+ 暗部（shadow1）+ 可选二级暗部（shadow2）。复杂材质最多到 3 阶，禁止渐变糊成厚涂。
- **硬边阴影（アニメ塗り）**：明暗交界是**清晰硬边**，不是柔和过渡。
- **阴影是"变色"不是"变暗"**：暗部向**蓝/紫**偏移（hue shift），而非简单降明度。例：肤色暗部偏玫红紫，不是灰。
- **高光极简且硬**：仅头发、眼睛、金属、湿润表面有少量硬高光（白或固有色亮版）。
- **环境/反射光**：角色与背景交界处加一条**冷色或暖色边缘光**，做出空间分离感（关键，治"违和"）。

### 1.3 主控色板（Master Palette）
| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色（品牌紫） | `#b06bff` | UI 强调、魔法、稀有 |
| 副色（霓粉） | `#ff6b9d` | 渐变搭档、强调 |
| 暗底 1 | `#1a1422` | 全局背景 |

**元素色语言（六属性，全项目统一）**
| 属性 | 主色 | 形态语言 |
| --- | --- | --- |

### 1.4 全局光照约定
- **主光源：左上 45°**，所有立绘/精灵/物件阴影方向统一。
- 战斗 / 大厅默认**冷调环境光 + 暖调点光**，特写 CG 可破例但需注明。

### 1.5 禁止项（红线）
❌ 厚涂/笔触感　❌ 写实比例与质感　❌ 像素/点阵　❌ 3D PBR 渲染感　❌ 纯黑描边　❌ 风格混搭（不同角色不同画风）

## 2. 立绘（Character Splash / 立绘）

### 2.1 规格
- **全身立绘**，比例 **7.5–8 头身**（成熟唯美向，对齐 BD2，非 Q 版）。
- **画布**：`1668 × 2388 px`（竖向 7:10），300dpi，透明背景 PNG（交付）/ WebP（运行）。
- **构图**：角色居中偏下，头顶留 8%、脚下留 5% 安全区；默认朝向镜头偏 3/4 侧。
- **姿态**：站姿带动态（contrapposto / 重心偏移），体现性格，不要立正。

### 2.2 分层 PSD 规范（为 DragonBones 拆骨做准备）
立绘**必须分层交付**，命名固定，便于绑骨：
```
splash.psd
├─ fx_front        前景特效（魔法、飘带）
├─ weapon          武器（可独立挥动）
├─ hair_front      前发
├─ face            └ brow / eye_l / eye_r / mouth（表情差分各自独立）
├─ head            头（含耳/角）
├─ body_torso      躯干
├─ arm_l_upper / arm_l_fore / hand_l   左臂三段
├─ arm_r_upper / arm_r_fore / hand_r   右臂三段
├─ leg_l_upper / leg_l_lower / foot_l  左腿三段
├─ leg_r_upper / leg_r_lower / foot_r  右腿三段
├─ hair_back      后发
└─ fx_back / cape  披风、后置特效
```
- 关节处**画到被遮盖处多留 30–50px**（绑骨旋转时不露缝）。
- 表情差分：每角色至少 **6 套**（平/喜/怒/哀/惊/羞），眉眼口分层可组合。

### 2.3 衍生裁切
| 用途 | 尺寸 | 来源 |
| --- | --- | --- |
| UI 头像（圆/方） | 256×256 | 立绘头部裁切 |
| 队伍/编队卡 | 420×560 | 立绘半身 |
| 对话半身 | 立绘原图，腰以上入画 |

### 2.4 服装（Costume）与稀有度
- 一角多服：每套服装=**独立立绘+独立骨骼+独立技能特效**，但**同一角色骨架命名一致**，可换皮复用动画。
- 稀有度视觉标识：R/SR/UR/星级用**边框 + 名牌 + 入场光效**区分，不改立绘本体画风。

## 3. 角色动画 · DragonBones 管线（重点章节）

### 3.1 为什么是 DragonBones（选型结论）
| 方案 | 授权 | Web 运行时 | 适配本项目 |
| --- | --- | --- | --- |
| **DragonBones** ✅ | **开源免费** | dragonBones.js + PixiJS | **选它**：免费、JSON 格式、骨骼+网格+IK，纯前端可跑 |
| Spine | 商业付费($/席位) | 官方 pixi-spine | 工业标准但要钱 |
| Live2D | 商业付费(营收超线) | Cubism Web | 专长"立绘呼吸/面部"，不擅长跑跳位移 |

> 结论：用 **DragonBones** 做全部角色骨骼动画，赛璐璐立绘手绘 + 骨骼绑定，纯前端 `dragonBones + Pixi` 接入现有 vanilla JS。

### 3.2 绑定流程（Pipeline）
1. 分层 PSD（见 2.2）→ 导入 DragonBones Pro。
2. 建骨架 → 蒙皮 → 对会形变的部位（披风、头发、裙摆、肌肉）加**网格 Mesh + 权重**。
3. 关键关节加 **IK**（手、脚），方便做攻击/踏步。
4. 做动画（见 3.4）→ 导出。

### 3.3 标准骨架命名（全角色统一，不可改）
```
root
└ hip
  ├ spine → chest → neck → head → (hair_f_1..n / hair_b_1..n / ear / horn)
  │                       └ face: brow_l/r, eye_l/r, mouth
  ├ shoulder_l → arm_l_upper → arm_l_fore → hand_l → weapon
  ├ shoulder_r → arm_r_upper → arm_r_fore → hand_r
  ├ thigh_l → shin_l → foot_l
  ├ thigh_r → shin_r → foot_r
  └ cape_1..n
```
> 同名骨架 = 动画可在同体型角色间**复用/重定向**，省一半工。

### 3.4 标准动画集（Animation Set，命名固定）
| 动画名 | 循环 | 帧率 | 时长参考 | 说明 |
| --- | --- | --- | --- | --- |
| `idle` | loop | 24 | 2–3s | 大厅/编队待机，呼吸+发丝飘动 |
| `idle_battle` | loop | 24 | 1.5–2s | 战斗待机，重心微晃 |
| `walk` | loop | 24 | 0.8s/循环 | 地图行走 |
| `run` | loop | 24 | 0.6s/循环 | 冲刺/进场 |
| `entry` | once | 30 | 1s | 出场登台 |
| `attack_normal` | once | 30 | 0.6–0.8s | 普攻，预备-发力-收 |
| `attack_skill` | once | 30 | 1–1.5s | 技能 |
| `ultimate` | once | 30 | 2–3.5s | 大招，可配镜头/CG/全屏特效 |
| `hit` | once | 24 | 0.3s | 受击硬直 |
| `die` | once | 24 | 0.8s | 倒地/消散 |
| `victory` | once/loop | 24 | 2s | 胜利 pose |

- **动画 12 原则**关键项必做：预备动作（anticipation）、跟随与重叠（follow-through，发/披风/武器滞后）、缓入缓出（slow in/out）、夸张（exaggeration 适度）。
- 大招建议分段事件帧（event frame）触发：`fx_charge` / `fx_hit` / `cam_shake` / `flash`，由代码挂特效与镜头。

### 3.5 导出与性能预算
- 导出 **DragonBones 5.x JSON**：`<id>_ske.json`（骨架）+ `<id>_tex.json`（图集表）+ `<id>_tex.png`（图集）。
- 纹理图集：**≤ 2048×2048**，2 的幂；超出则多图集。
- 性能预算（每角色）：骨骼 ≤ 60、网格顶点合计 ≤ 1500、图集 ≤ 2 张。
- 运行时：`dragonBones.PixiFactory` + PixiJS，渲染层叠加在现有战斗舞台上。

## 4. 游戏精灵 / 战斗单位（Battle Sprites）

- **战斗单位 = 立绘骨骼动画本体**（同源原则），不另画 chibi。前中后排用缩放表现纵深，呼应现有 `ROWCFG`：
  - enemy 后/中/前：scale 0.70 / 0.78 / 0.86
  - ally 前/中/后：scale 0.94 / 1.02 / 1.10
- **锚点**：脚底中心（接地点），所有单位统一，便于站位与接地阴影。
- **接地阴影**：每单位脚下一枚椭圆软阴影（屏幕混合），随站位缩放，强化"踩在场景里"。
- 地图行走小人（若启用步行场景）：**同一套骨骼的 `walk/run`** 缩放使用，绝不另起像素小人。

## 5. 场景元素（Environments）

### 5.1 战斗场景（HD-2D 分层）
分 4 层做视差：`bg_far`（天空/远景）→ `bg_mid`（建筑/树线）→ `bg_near`（地面装饰）→ `ground`（站位地面，含光斑）。
- 色调**统一压暗 + 加雾**，让角色（边缘光）跳出来。
- 主题色板（与剧情卷对应）：森林=青绿、矿洞=暖橙赭、魔王城=暗红紫、永夜=冷蓝紫。

### 5.2 大厅 / UI 背景
- 预留**动态背景位**（视差/粒子/缓动光），主角立绘 `idle` 叠加其上（呼应现有 `.lobby-art-ph`）。

### 5.3 融合规则（治违和）
角色与场景之间必须有：①边缘光　②接地阴影　③统一色温（场景 LUT/叠色）。三者缺一不可。

## 6. UI 美术

- **设计语言**：暗色奇幻 + 紫金 + 毛玻璃（已在 CSS 变量中确立，沿用 `--accent/--accent-2/--gold/--panel`）。
- **组件库**：按钮、卡片、弹窗、进度条、稀有度框、标签 chip、货币图标——统一圆角、描边、阴影规则（见现有 `style.css`）。
- **图标体系**：功能图标统一**面性 + 细描边**风格，48px 栅格，描边 `1.5px`，圆角 `2px`；占位 emoji 逐步替换为统一图标集。
- **字体**：中文 PingFang/思源黑；数字用等宽数字；标题可加装饰衬线/描金。
- **切图**：9-slice 拉伸图、@1x/@2x/@3x 三套，WebP 优先。

## 7. 游戏 CG / 剧情演出（Story CG & Cutscene）

- **剧情演出 = 立绘骨骼动态 + 对话框 + 分镜**（沿用现有 `story.js` / `comic.js`）。
- 对话中立绘：用 DragonBones 的 `idle` + **表情差分切换 + 简单口型**（mouth 骨 2~3 帧），入退场用 `entry`/淡入。
- **全屏 CG**：关键剧情节点的一次性大图，赛璐璐成图，`2388×1668` 横，可加轻微 Live2D 式呼吸或粒子。
- **漫画剧场**：黑白/单色分镜（呼应现有 comic 系统），同一赛璐璐线条规范。

## 8. 技能特效（VFX）

- **风格**：赛璐璐特效——**硬边光形 + 序列帧 + 少量粒子**，禁止糊状发光堆叠。
- **元素形态语言**：见 1.3 表（火尖锐上扬 / 水流动弧形 / 风螺旋速度线 / 土块面棱角 / 光放射 / 暗蚀刻扭曲）。
- **三段结构**：`charge`（蓄力前置）→ `impact`（命中爆点）→ `linger`（残留消散）。
- **制作**：优先**序列帧 sprite-sheet**（AE/CSP 输出）或 DragonBones 特效骨骼；通用打击感（冲击波、速度线、闪白、震屏）走代码层。
- **性能预算**：单技能同屏序列帧 ≤ 3 层、粒子 ≤ 80。

## 12. 一致性铁律（QA 速查 · 一页）

每件美术资产入库前自检：
- [ ] 赛璐璐 2–3 阶硬边阴影，暗部**变色**而非变暗
- [ ] 线条非纯黑（最深 `#241a2e`），线宽分级
- [ ] 主光源左上 45°，方向与全局一致
- [ ] 配色取自主控色板 / 元素色板，无越界杂色
- [ ] 角色比例 7.5–8 头身，与同批一致
- [ ] 角色有边缘光 + 接地阴影（不违和）
- [ ] 命名、尺寸、图层结构符合 §9
- [ ] DragonBones 骨架命名 = 标准命名，动画集齐全（§3.3/3.4）
- [ ] 性能预算达标（骨骼/顶点/图集/粒子）
- [ ] 放进游戏里与相邻元素**摆在一起不割裂**

> 一致性是第一优先级。任何"好看但不统一"的资产一律打回。
