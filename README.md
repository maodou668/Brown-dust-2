# 棕色尘埃 2 · Brown Dust 2（同人复刻）

一款受《棕色尘埃 2》启发的浏览器回合制 RPG。纯 HTML / CSS / JavaScript 实现，**无需任何依赖或构建步骤**，打开 `index.html` 即可游玩，并支持手机竖屏。

> 本项目为学习/演示用途的同人作品，与 Neowiz 官方无关。

## ▶ 如何运行

**最简单（手机也适用）**：直接用浏览器打开 `game.html`——这是一个把所有 CSS/JS 内联在一起的**单文件版本**，无需任何外部资源，下载到手机后用浏览器打开即可游玩。

> 单文件版本由 `node scripts/build.js` 从 `index.html` + `css/` + `js/` 自动生成。

或用浏览器打开项目根目录的 `index.html`（分文件版本）。

或启动一个本地静态服务器（推荐，避免个别浏览器的本地文件限制）：

```bash
# Python
python3 -m http.server 8000
# 然后访问 http://localhost:8000

# 或 Node
npx serve .
```

## 🎮 核心玩法

| 系统 | 说明 |
| --- | --- |
| **佣兵收集** | 通过招募（抽卡）获取 3★~5★ 佣兵，每名佣兵有独立属性、元素与技能 |
| **回合制战术战斗** | 基于速度的行动顺序，手动选择技能与目标，敌方由 AI 操控 |
| **前后排阵型** | 战士/守护者位于前排，法师/游侠/治愈者位于后排，技能可命中单体、整排或全体 |
| **元素克制** | 火→风→地→水→火，光↔暗，克制时造成 1.3 倍伤害 |
| **SP 充能** | 行动积累 SP，释放强力技能；普通技能不耗 SP |
| **护盾 / 增益 / 减益** | 护盾吸收伤害，可提升攻防或降低敌方防御 |
| **角色养成** | 用金币升级提升属性，战斗获得经验自动升级 |
| **关卡推进** | 5 个递进关卡，含 2 场 BOSS 战，通关解锁后续 |
| **存档** | 自动存储在浏览器 `localStorage`，可一键重置 |

## 🗂 项目结构

```
index.html        页面骨架与脚本引用
css/style.css     暗色奇幻风格 UI 样式
js/
  data.js         静态数据：角色 / 技能 / 敌人 / 关卡 / 抽卡池
  game.js         游戏状态、存档、养成、抽卡逻辑
  battle.js       回合制战斗引擎（伤害/元素/护盾/buff/敌方 AI）
  ui.js           各界面渲染、弹窗、角色详情、抽卡
  main.js         战斗界面交互 + 应用入口与路由
```

## 🧭 上手建议

1. 新游戏赠送泰瑞德与米娜，并自动编入队伍。
2. 先打第 1 关「艾尔玛森林 · 入口」积累金币与宝石。
3. 攒够 💎 去「招募」抽取强力佣兵（90 抽保底出 5★）。
4. 在「佣兵」页点击角色升级、编队（最多 4 人）。
5. 逐关推进，最终在「魔王城 · 王座」击败魔王巴尔。

## 🛠 技术说明

- 零依赖、零构建，纯静态资源。
- 战斗引擎与游戏逻辑同 UI 解耦，`battle.js` / `game.js` 可在 Node 环境无头运行与测试。
