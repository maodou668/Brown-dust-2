# 《棕色尘埃 · 烬火行纪》— 剧情圣经与轻小说

> 本目录是整个游戏剧情的「底层文本」。我们先用一本日式轻小说奠定世界观、人物弧光与主线脉络，
> 之后游戏内的剧情演出（对话脚本）、漫画分镜都以此为蓝本改编，确保「像在看一部动漫」的统一质感。

## 一、为什么先写小说

当前游戏内剧情是零散的关卡前对话，缺少：世界观的厚度、人物的动机与成长、贯穿始终的悬念与主题。
轻小说先行，能一次性把这些「地基」打牢：

- **世界观**：六元素、褐色尘埃的侵蚀、永夜的轮回。
- **人物弧光**：每名可抽取角色都有自己的来处、伤口与转变，而非一张立绘。
- **主线悬念**：魔王只是表象，真正的敌人藏在「永夜」与一场被遗忘的轮回里。
- **基调**：少年热血 + 群像羁绊 + 逐渐揭开的宏大谜底，正是 BD2 的叙事手感。

## 二、标题的含义（「棕色尘埃」）

魔物所经之处，草木、城郭、乃至人，都会褪色、风化，最终崩解为一捧**褐色的尘埃**。
大陆正一寸寸沦为尘土。阻止世界化为尘埃，就是这群佣兵踏上旅途的理由——这也是「棕色尘埃」之名的由来。

## 四、登场人物速查（与游戏角色一一对应）

- **指挥官**（玩家）：沉默而目光锐利的异乡人，能在混战中「看见」战局的走向，是佣兵团真正的大脑。
- **泰瑞德**：怀抱英雄梦的乡村少年，佣兵团的发起人与心脏，炽烈如火。
- **米娜**：胆小却坚强的小小药剂师，背着比自己还大的药箱。
- **莉可莉丝**：炽焰魔女，烬火小镇唯一的幸存者，毒舌护短。
- **贾丝蒂亚**：圣盾骑士团最后的传人，以身为盾的誓约者。
- **希尔**：暗巷长大的孤儿神射手，话少箭准。
- **萝**：能听见「光」低语的祭司。
- **海莲娜 / 黛安娜 / 加西亚 / 莉亚**：疾风剑士、碧水法师、岩石壁垒、草原游侠。
- **反派**：魔王巴尔、巨魔王、以及永夜深处的暗影女皇涅夫提斯。
