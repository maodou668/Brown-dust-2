## 2. 恐怖感的三类做法（通用方法论，量产时照抄）

### 2.1 Sprite 级微差分
- 正常村民 NPC：标准 7 帧呼吸 idle。被替换 NPC：仅第 4 帧改 2 处像素（右眼外扩 1px、嘴角上提 1px），8fps 下停留 125ms/循环。
- 制作：PixelLab 出基础 idle 后由脚本改像素（`scripts/npcvariant.js`），不重新生成。
- 递进：ch1 异常帧 1/7 → ch3 起 2/7 → ch4 教堂场景全员异常（玩家此前见过正常版，对比靠记忆）。
- 禁止：不加红光/音效提示/特殊名牌。发现异常的唯一途径是玩家自己看。

### 2.2 NPC 对白状态机
- 每个剧情 NPC = `states[] + ask 计数器`。范式三态：
  - A 正常：同一问题重问，措辞随机 3 选 1。
  - B 已替换未目击：重问 → **逐字符完全相同**的回复（含标点）；第三问 → 说出该 NPC 不可能知道的玩家行动。
  - C 已目击铁证：对话选项只剩[离开]；朝向锁定跟随玩家（复用 8 向 idle）。
- 玩家无法用系统 UI 分辨状态，只能靠对白内容和 §2.1 的帧。

### 2.3 场景重访 diff
- 每个地图节点存 A/B/C 三版道具清单，按剧情进度切换。差异必须**可数**：晾衣绳 6→4 根、稻草人 1→2 个、水桶左→右。
- 不弹提示文本。黛安娜负责唯一的半提示可选台词（见行为卡）。

## 4. 十六人行为卡（写行为和台词，不写性格标签）

> 格式：职能 / 场景行为脚本×2 / 台词样例×3 / 禁语。台词写作全局禁令见说明书剧情章。

### 泰瑞德（战士·火 | 团长）
- 行为：`whisper` 触发时反应台词永远接错茬（听到了但听不懂，全团唯一）。样例：（卡佳停步望西后）"……饿了？前面镇上有卖热汤的。"
- 行为：结算戏把自己那份钱推给米娜补药材，说"记账上"。账本道具查看：他那页全是欠条。
- 台词：战后清点"都活着？——好，那就是赢了。" / 接单"钱少事多，还没人谢。接了。" / 对教会兵"你们的灯是借的。我们的是自己点的。"
- 禁语：不说"羁绊""伙伴的力量"式总结；不解释世界观。

### 米娜（药师·风）
- 行为：营地熬药时哼歌。音频规格：5 音动机=井事件 BGM 动机（玩家听出来时已到卷二）。
- 行为：被问药方来历：问 1 次→"梦里一个老婆婆教的呀。"（立绘无差分，语气正常）；问 2 次→"哎？你之前也这么问过？"——无论玩家实际问没问过。
- 台词：治疗"别动。疼说明你还分得清疼。" / 配药"这瓶闻着像杏仁的不能碰，碰了记得告诉我遗言。" / 逃跑"我跑得快是因为我练过，不是因为我怕！"
- 禁语：不卖萌自称；不说"大家"开头的鼓劲话。

### 莉可莉丝（法师·火 5★）
- 行为：进入任何带地窖/锁门的场景，自动脱队走到门前停 2 秒归队。对话："……没什么。这锁是从外面锁的。"（全场景共用同一条）
- 行为：ch2 结尾唯一一次主动搭话指挥官："你听不见那东西，对吧。……真好。"（此前她从不主动对话）
- 台词：点火"退后。我控制得住火，控制不住你们乱跑。" / 对缉捕兵"火不挑人。这是它唯一比你们教会强的地方。" / 被谢"谢火。我只是划了根火柴。"
- 禁语：不哭诉身世；老家的事在 ch2 前一个字不提。

### 贾丝蒂亚（守护·光）
- 行为：队伍进教会类建筑，她的跟随小人固定滞后 2 格进门。无台词说明。
- 行为：装备栏专属饰品「刮花的徽章」，描述只有一句："烛火图案被利器反复刮过。"
- 台词：ch4 前被问教会"问委托的事。别的我按小时收费。" / 举盾"站我左边。右边我看不见的时候比较多。" / ch4 决裂"第四趟车回来是空的。我数了三遍。"
- 禁语：ch4 前不控诉教会；不做信仰演讲。

### 希尔（弓手·暗）
- 行为：对可疑 NPC 执行「确认」：小人走到目标正面站定 7 秒（玩家可见倒计时无 UI，纯站着），然后回队报"是人"或什么都不说。方法从不解释。
- 行为：夜营固定守上半夜。跟他说话只在此时有额外对白分支。
- 台词："是人。"（确认通过的全部台词） / "箭比我先知道。" / 被问怎么确认的："你不会想学的。学会就回不去了。"
- 禁语：单句超过 15 字的台词原则上不给他。

### 萝（祭司·光）
- 行为：`whisper` 事件她的反应独一份：面向声源方向回嘴。样例："吵死了！他说不去就是不去！"（全团这才知道低语刚才"说"了什么方向的事）
- 行为：教堂场景她会自动跑到烛台前把歪的蜡烛摆正，摆完补一句"不是给你们教会摆的，是给火摆的。"
- 台词："光的声音今天有杂音，像隔壁修锅的。" / "我听得见，但我可以不听。这是我的自由。" / 治疗时"别谢我，谢完他又该得意了。"（不解释"他"是谁）
- 禁语：不天然呆装傻；她听得懂低语这件事全团最清楚。

### 海莲娜（骑士·风）
- 行为：每晚营地写巡逻日志。道具可查看：收件人栏写着已不存在的哨所番号，内容全是格式化军报。
- 行为：行军中她永远走队列最外侧，路过岔路口自动停 1 秒看一眼再跟上。
- 台词："哨所七人，巡逻归队，缺员七。……报告完毕。" / "队形。散着走的先死。" / 被问为什么还写日志："上级没批我停笔。"
- 禁语：不悲情回忆战友；哨所的事只从日志道具透出。

### 黛安娜（法师·水）
- 行为：场景重访 diff 的半提示由她触发（可选对话）："稻草人。昨天路过的时候，我记的数和现在不一样。……可能是我记错了。"（永远以"可能是我记错了"收尾）
- 行为：营地看书用香计时，香灭合书，无论看到哪。玩家此时对话她只回："香灭了。明天再问。"
- 台词："我只负责记录，不负责解释。解释是危险的。" / "这本书第三章不见了。装订没坏，页码连续。就是没有第三章。" / "别背我抄的东西。默写会出事。"
- 禁语：不说教式科普世界观；她知道的比说的多得多。

### 加西亚（守护·地）
- 行为：进入室内场景自动用指节敲最近的墙 2 下（音效：实/空两种回声），空音时他会站在那面墙前直到队伍离开。
- 行为：ch2 矿镇他带路，地图上他替代指挥官在前（唯一一章）。
- 台词："墙是空的。谁家的墙后面会有房间不开门？" / "矿上的规矩：灯灭了不喊名字。喊了它就知道你在。" / "我扛得住塌方。扛不住名单。"
- 禁语：憨厚大叔式打哈哈不要；他的玩笑只关于饭量。

### 莉亚（弓手·地）
- 行为：全团食物安检：吃饭前她逐份闻 3 下（小人动作循环 3 次）才开饭。被问就一句："草原的规矩。"
- 行为：野外场景她的视线（朝向）永远和队伍行进方向差 90 度——她在看两侧。
- 台词："兔子不该站着看人。上个月开始，兔子站着看人。" / "能吃。"（安检通过的全部台词） / "猎物跑是正常的。不跑的才要小心。"
- 禁语：不咋咋呼呼；她的警告全部是陈述句。

### 蕾菲西亚（治疗·光）
- 行为：路过墓地类场景自动停步唱一小节（4 秒，音频同一旋律），唱完继续走。翻过土的坟她多唱一节。
- 行为：她的治疗技能演出比别人慢 0.5 秒起手——先合手再施法。
- 台词："唱歌不是给死人听的，是给土听的。土安静，人才安静。" / "这座坟翻过。最近七天之内。" / 被问歌词含义："词不重要。调子对了就行。"
- 禁语：圣女式慈爱腔不要；她谈死亡像谈天气。

### 莉洁奈特（剑士·风）
- 行为：对战缉捕队时，战斗插话报敌方姓名并纠正其姿势："汉斯。手腕又抬高了。我教过你多少遍。"（敌方缉捕兵有姓名池，她认识其中一半）

- 台词："我教出的学生一半在追杀我。说明我教得不差。" / "剑没有立场。握剑的手有。" / "姿势不对，死得更快。仅此而已。"

### 奥尔斯坦（守护·地 5★）
- 行为：任何有门的场景，他数进出人头（头顶冒极小的计数气泡，只有指挥官视角可见）。数目对不上时他不说话，只是不走。

- 台词："进去九个。出来九个。可以走了。" / "城门的活教会我一件事：门没有错，错的是放进来的东西。" / ch8 前唯一一次谈当年："那晚我放进来一队人。第二天，那条街没有人记得自己昨天见过谁。"

### 格蕾西亚（法师·水）
- 行为：营地永远最后一个睡、第一个醒（营地场景时间轴脚本固定）。她煮的茶有专用道具图标，效果文本："驱除睡意。她坚持所有人都该少睡点。"

- 台词："我在研究所睡着了一场讲座。醒来时，教室里坐满了认真听讲的人。讲台上没有人。" / "困不是问题。梦才是。" / "茶凉了也喝掉。这是命令。"
- 禁语：冰山美人式沉默不要；她怕的东西很具体，就是睡着。

### 莉亚特丽丝（弓手·火）
- 行为：战后打扫战场她负责烧（场景固定火堆动画）。她的背包侧面挂一个铁盒道具，查看文本："上了三道锁。锁眼有烧灼痕迹。"
- 行为：ch6 她的身世章前，任何人问铁盒 → 她把话题转向今天烧了几件东西（具体数字）。
- 台词："烧了七年。纸、布、木头、骨头，都听火的话。有些东西不听。" / "教会的规矩里只有'必须火化'，没写'烧不掉怎么办'。" / "今天烧了十一件。第十二件在盒子里。"
- 禁语：不搞纵火狂人设；烧东西对她是工序。

### 罗恩（战士·光）
- 行为：引用教典后固定补一句"……应该是这么写的。"（补句的迟疑随章节递增：ch1 语气词 0 个 → ch4 起补句前多一个"……"）
- 行为：教堂场景他自动在门口划烛火手势，ch4 之后这个动作脚本删除（不提示，玩家自己发现）。
- 台词："《烛火书》第三十七节说，光不挑灯盏。……应该是这么写的。" / "我还没正式入会。所以严格来说，我不算叛教，算旷课。" / ch4 后："那一节我背错了很多年。不是'光不挑灯盏'，是'灯盏不挑光'。意思全反了。"
- 禁语：不做信仰崩溃大哭戏；他的动摇全部走"背错经文"这条线。

## 5. 台词写作铁律（全角色通用，写进说明书剧情章）
1. 设定不从嘴里念。世界观信息走场景、道具描述、旁白，人物只谈眼前的事。
2. 短句优先。一句话里塞两个信息就拆成两句。
3. 允许答非所问、被打断、说一半。每场戏至少一处。
4. 每场戏必须有一个可写出来的目标或冲突（谁想要什么，谁挡着）。写不出就删场。
5. 遮名牌测试：盖住说话人名字，凭句子认人。认不出=返工。
6. 幕尾留钩子：最后一拍是新信息或未答的问题，不是总结陈词。

## 6. 生产流程（每章循环）
1. 我出分场大纲（表格：幕/演出层/一句话事件/触发器）→ 用户过目。
2. 写剧本 DSL（`js/story2/chX.js`）→ 游戏内直接可播 → 用户玩，逐句改味。
3. 定稿 → artgate 式闸门：遮名牌抽测 5 句 + 每章至少 3 种演出层 + 禁语 grep 扫描（`scripts/dialoguegate.js`，禁语表见行为卡）。

## 7. 范文库（用户校准样本 · 写任何台词/旁白前先读，向它对齐）

> 用户提供，2026-07。语感基准。写完一场戏，逐句问：这句放进下面这段里违和吗？违和=返工。

```
（背景：主角来到被怪物血统侵蚀的印斯茅斯镇，在连锁杂货店里，向全镇唯一正常的外来年轻店员打听情况。）
"这里的人……得的是某种遗传病吗？"我压低声音问。
年轻人立刻警惕地往落满灰尘的窗外看了一眼，手里还在机械地用抹布擦拭着罐头："他们管那叫'印斯茅斯长相'。你仔细看他们的脖子，两边有很深的褶子，眼睛从来不眨。老辈人更严重，连头发都没有。他们走路一趿拉一趿拉的，脚板根本抬不起来。"
"镇上的医生不管这事吗？"
"没人管。只要到了一定岁数，他们就会退隐，搬进那几条根本不点灯的死胡同里，成天关着门。"年轻人咽了口唾沫，声音低得几乎听不见，"听我一句劝，老兄，天黑前千万要坐末班大巴离开这鬼地方。有时候夜里……你能听见那些空无一人的屋子里，传出像大肥鱼在烂泥里翻腾的'吧嗒、吧嗒'声。"
他把擦好的罐头重重磕在货架上：
"只要等下个月领了薪水，攒够买车票的钱，我连铺盖都不卷，立刻滚出这个镇子。"
```

**从范文提炼的六条手法（叠加在 §5 铁律之上）：**
1. 恐怖长在**可验证的身体细节**上：脖子的褶子、从来不眨的眼、趿拉的脚板。写"诡异"之前先回答"具体哪里不对"。
2. 说话人有**贯穿的手部动作**：擦罐头、咽唾沫、把罐头磕在货架上。ADV 里动作走旁白拍，插在台词中间。
3. **口语的糙劲**："听我一句劝，老兄""滚出这个镇子""这鬼地方"。宁糙勿雅。
4. 当地人给恐怖**起了自己的词**（"印斯茅斯长相"）——世界观词汇由角色嘴里自然带出，不由旁白定义。
5. **声音细节压轴**：大肥鱼在烂泥里翻腾的"吧嗒、吧嗒"。一场戏最瘆的一笔留给声音/触感。
6. **问短答长，答里带私心**：主角问句极短；答话人说着说着落到自己身上（下个月就跑）。信息永远搭在人的欲望上。

### 7.2 情景范文·探索/遭遇异常（斯特鲁加茨基《路边野餐》· 用户供 2026-07）

```
瑞德没有理会新手的抱怨，从口袋里掏出一把生锈的螺母，上面绑着碎布条。
他用力把一颗螺母朝前方的空地上抛去。螺母在空中划过一道弧线，突然，就在离地还有半米的地方，它像被一柄看不见的千吨大锤砸中，在一声刺耳的爆鸣中瞬间被压成了一块铁饼，深深嵌进泥土里。
"看到了吗？"瑞德头也没回，声音里没有任何波澜，"那是'蚊子秃子'（重力异常点）。如果你刚才走过去，你的脊椎骨现在就已经从靴子底被挤出来了。"
新手的脸色煞白，两条腿控制不住地打摆子，一句话也说不出来。
"听好，小子。"瑞德点上一根烟，指着地上的泥巴，"我踩哪儿，你就踩哪儿。你要是敢偏离我的脚印半寸，我就只能把你的名牌从那一摊烂肉里抠出来带回去了。现在，提上设备，跟紧我。"
```
**手法**：①异常客观化/物理化——写螺母被压成铁饼嵌进泥土，不写"可怕的威压"②职场化冷酷警告——老手没有恐惧只有防范经验，死法陈述到"脊椎骨从靴底挤出来"③动作驱动——面对致命危险，角色关注点仍是点烟/指脚印/提设备。**适用**：井异常、换人区探索、掌灯人的作业规范（灯照到哪走到哪=瑞德的脚印规则）。

### 7.3 情景范文·战后/任务交付（萨普科夫斯基《猎魔人》· 用户供 2026-07）

```
杰洛特解开绳子，那坨散发着刺鼻恶臭、长满脓包的庞大尸体"砰"地一声砸在酒馆的木地板上，黑色的血水顺着缝隙流到了村长脚边。酒馆里的人全都被恶心得捂住鼻子连连后退。
村长惊恐地盯着那堆烂肉，结结巴巴地说："老天爷……这……这就是下水道里的恶魔？你竟然真的杀了它……你是神明派来的使者！"
"我不是使者，我是拿钱办事的。"杰洛特没有看地上的怪物，他把沾满黏液和血污的剑在村长的桌布上用力擦了擦，然后把空荡荡的钱袋拍在桌面上。
"我们说好的，五十个奥伦金币。另外，"杰洛特指了指自己被撕裂的皮甲袖口和流血的手臂，"它抓烂了我的护甲，我还喝了一瓶燕子魔药。算上护甲修补费和药水钱，你得再加五个奥伦。"
```
**手法**：①拒绝道德高地——NPC 递"使者"高帽时用尾款打断②物理损耗——代价是撕裂的皮甲/喝掉的药水/修补费，不是灵魂疲惫③感官肮脏——恶臭、脓包、在桌布上擦剑。**适用**：每章战后结算戏、委托交付、教会/贵族试图给团戴帽子的场合。

### 7.4 情景范文·营地/面对死亡（雷马克《西线无战事》· 用户供 2026-07）

```
炊事班长海因里希看着面前稀稀拉拉的队伍，傻眼了："其他人呢？难道都没了？"
"剩下的都在地里躺着呢。"卡特一边说，一边把饭盒递过去，"不管怎样，豆子汤你得给我们盛满。"
"那不行，"炊事班长摇摇头，"口粮是按一百五十人配给的，我不能把死人的那份发给你们。"
卡特一脚踹在餐车的轮子上："你是不是脑子进水了？这八十人才是今天连队的全部！那七十个人已经吃不了饭了，但活人还得活下去！赶紧把双份的豆子汤和香肠给我装满！"
旁边的穆勒凑过来，盯着长条凳上一双崭新的、皮质极好的飞行员靴子，咽了口唾沫："肯梅里希昨天穿的就是这双靴子。但他现在连腿都没了。卡特，等会儿吃完饭，咱们去问问医护兵，能不能把这双靴子留给我。"
```
**手法**：①悲伤物化——同伴的死转化为多出来的一份豆子汤和一双可继承的靴子②粗暴生存欲——只谈香肠口粮和今晚怎么活③极度克制——"剩下的都在地里躺着呢"一句带过尸横遍野。**适用**：营地休整戏、村庄失踪/被替换后的善后、卷二伤亡戏（严禁悼词）。
