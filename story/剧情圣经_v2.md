# 棕色尘埃 · 烬火行纪 —— 剧情圣经 v2（商业化第一季 · 工作蓝本）

> 本文件是把 demo 拔高到「商业化可玩版」的**故事地基**：世界观硬设定、人物关系网、第一季分章战斗节拍表、季度路线图、演出规格、写作规范，全部一处定死。
> 与既有 `story/README.md`、两卷小说、`js/lore.js` 同源；本 v2 是**工作蓝本**，落到 `js/story.js` 演出时以此为准。
> **全原创 IP**：褐尘 / 永夜 / 涅夫提斯 / 巴尔 / 16 人皆为本作自有设定，可自由商业化。

## 0. 定位与目标
- **品类**：横版侧视抽卡 RPG（Brown Dust 2 风的演出手感 + 追番式季度更新）。
- **第一季（S1）范围**：第一卷《启程之烬》——组建佣兵团 → 击败「假魔王」巴尔 → 揭开永夜伏笔，**结尾强钩子**。
- **时长目标**：**12h engaged = 主线 7–8h + 支线/养成 4–5h**。
- **主线体量**：约 **6 章 · ~30 关战斗 · ~35 场剧情演出 · 16 段角色羁绊**。
- **不是从零**：已有 16 角色美术、序章、多关、多段支线——本季是往上**扩建 + 换血重写**。

## 1. 基调与写作规范（锁死 · 所有对白都按这个来）
> 这一节是防「AI 味 / 中二念悼词」的硬闸门。任何人（含我）写演出前先过一遍。

- **人话关（第一铁律）**：写完每句先问——「这是活人当场会说的话，还是我在配旁白/抖机灵？」凡像判词、格言、收麦克风的（如"烫的是别人"），一律打回重写。
- **默认轻快**：90% 篇幅是快节奏、口语、带点吐槽的日常与推进；文体轻、旁白短句、画面感强，不堆文艺意象。
- **傲娇写成"慌"，不是"忧郁"**：毒舌/别扭源于**当场被戳到、恼羞成怒**（缩手、扭头、放狠话），不是对着空气朗诵伤痛。
- **情绪靠动作与吐槽漏出来**，不靠内心独白金句。添柴的手停半空 > "我的心在滴血"。
- **只在真正的爆点压一次沉**，而且要说得平。一场戏最多一个重锤，其余都轻。
- **具体质感**：用一件不起眼的具体旧物/气味/数字把情绪钉住（"一坛没封口的梅子" > "三百二十七"）。
- **每个人有口癖指纹**（见 §4）：把名字盖掉也认得出谁在说话。
- **场景必须"动一寸"**：哪怕搞笑戏，也要让某段关系或某条线索往前挪。
- **旁白只写"看得见的动作/发生了什么"**，绝不替读者升华总结主题。
- **指挥官（玩家）声音**：惜字、只读细节（重心、旧伤、扣带声），可疲惫、可承认不知道；不报术语、不当智者。

## 2. 世界观硬设定（개연성地基 · 因果要自洽）

### 2.1 褐尘（Brown Dust）
- **是什么**：魔物侵蚀万物后留下的东西。被碰过的草、树、城墙、人，会**褪色 → 变脆 → 散成褐色粉末**。
- **本质**：永夜女皇涅夫提斯的「呼吸」。**尘埋满大陆之日 = 她苏醒之时。**
- **规则（写战斗/演出要守）**：
  - 打倒普通魔物 → 它化成褐尘消散（干净）。
  - 被尘**深度侵蚀**的东西（矿洞、巨魔王）→ 产生更浓、**带「意志」**的尘：会主动侵蚀、操纵宿主。
  - 尘不可被"拂掉/净化"——它是女皇的呼吸，只能**拖延**（这是巴尔存在的意义），S1 不给"净化褐尘"这种解法，避免逻辑崩。
- **误区澄清**：世人以为褐尘是"魔王的瘴气"。真相要到矿洞（第3章）才第一次露头——尘有自己的意志，"魔王"未必是源头。

### 2.2 六元素
火、风、地、水、光、暗，相互克制，是战斗克制与魔法体系根基。角色/魔物皆带元素（数值见 `js/data.js`）。

### 2.3 永夜与千年轮回（S1 的核心谜底）
- **永夜**：一段被人**故意从史书里抹掉**的历史。世界曾被褐尘埋过一次，陷入不见天日的永夜。**每隔一千年，永夜想再回来一次。**
- **巴尔的真相**：世人眼中的「魔王巴尔」，其实是**封印永夜女皇的最后一道锁齿**（一颗正在生锈的齿）。他撒褐尘、演魔王，是用「拖延」延后永夜——**他是狱卒，不是元凶**。
- **打倒巴尔的代价（S1 结尾反转）**：击败巴尔 = 打断了最后一道锁齿 → **反而让永夜来得更快**。但换个角度：锁本会锈、迟早断，与其等它自己断时无人能挡，不如断在这群还愿意拼命的人手里——把"那扇门"从黑暗手里抢到自己手里。
- **涅夫提斯**：永夜女皇，S1 全程**不露真身**，只作为终极悬念与结尾一线阴影存在（S2 主役）。她的"敌意"不是狂暴，而是一种想哄整个世界安眠的、温柔的慈悲——这是本作反派哲学的核心，S2 展开。

### 2.4 时间线（年表 · 大陆历）
- **约 -1000 年**：上一次永夜；女皇被封印，巴尔成为锁齿，开始千年的"拖延"。
- **1013 年**：烬火镇一夜大火（褐尘降临的早期征兆），三百二十七人化尘，莉可莉丝是唯一幸存者，掌心自此住进一簇火。
- **1024 年（S1 当下）**：褐尘明显加剧，魔物涌出，边境村镇接连沦陷。泰瑞德与指挥官相遇，佣兵团启程 →（六章）→ 击败巴尔 → 永夜伏笔揭开。
- **S2（第二卷）**：巴尔陨落三月后，永夜降临，涅夫提斯苏醒。

### 2.5 主要地点（S1 动线）
艾尔玛森林（启程）→ 灰环镇商道 → 废弃矿洞（尘·意志首现）→ 途中原野 → 诅咒山脊（巨魔王）→ 魔王城（巴尔 / 永夜之门）。
其它：烬火镇（已毁·莉可莉丝故乡）、赤砂镇（莉可莉丝独守的小镇）。

### 2.6 势力
- **佣兵团（玩家阵营）**：泰瑞德发起、指挥官为脑，一支从三人起家的杂牌队伍。世人走投无路时想起的名字。
- **各地骑士团/神殿（多已残破）**：圣盾骑士团（贾丝蒂亚是最后传人）、神殿/圣山（萝、蕾菲西亚）、以及 S2 才登场的苍空/黎明/极北等团——为角色出身提供背景，多在战火/褐尘中凋零。
- **魔物与巴尔的爪牙**：被褐尘操纵或滋生的魔物；巨魔王等"被尘泡透"的强敌。
- **永夜女皇及其造物（S2 主敌）**：S1 只留阴影。

## 3. 主题
**第一季：「趁世界还没散成尘之前，把它抢回来。」**
少年热血 + 群像羁绊 + 明知末日将至也偏要迎上去的选择。反派不是纯恶，而是"拖延末日的狱卒"——第一季就埋下"真正的敌人是一种温柔的绝望"这条引线，S2 引爆。

## 4. 人物（16 + 指挥官 + 反派）

### 4.1 核心三人（序章即在）
- **指挥官（玩家）**：外来旅人，佣兵团的脑。能在混战里"看见"重心与走向，预判半拍。**口癖指纹**：惜字，只读具体细节（"看它后腿""扣带声很脆"），从不报术语、不说漂亮话；偶尔疲惫，会说"我不确定"。弧光：一个走得太安静的人，被泰瑞德那声"还相信能改变什么"的呐喊留下。
- **泰瑞德（Teried）· 火**：见习剑士，佣兵团发起人与心脏。梦想组团、亲手了结魔王之乱。炽烈、不服输、会感染人、**厨艺极差**（团队黑历史）。**口癖**：一激动就说不利索、句子冲、爱喊"看我的"；数三永远数不到三。弧光：从"喊了三年的空话"到真的带队走到魔王面前。
- **米娜（Mina）· 水/药**：跟祖母学制药的少女，背着比自己还大的药箱。胆小但跑得快。**口癖**：结巴 + 说完立刻道歉（"我、我……对不起"）。弧光：从"抖着腿等死"到关键时刻鼓起勇气递上救命药。

### 4.2 第一季登场（可玩，随主线加入）
- **莉可莉丝（Lecliss）· 火**：烬火镇大火唯一幸存者，掌心住着一簇既杀她全镇、又是她唯一信得过之物的火。表面高傲毒舌，内里极度护短、极度怕再失去人。**口癖**：关心永远裹在威胁里（"再盯，小心我烧你眉毛""别死在我面前，否则饶不了你"）。弧光：从孤独燃烧十一年，到愿意为这群人再护一次。**秘密**：她的火其实是"褐尘之火"的残留，与永夜有隐秘关联（S2 线索）。
- **贾丝蒂亚（Justia）· 光/地**：圣盾骑士团最后的传人，立"以身为盾"的誓。沉默寡言，总在最危险处挡在人前。**口癖**：短、正式、命令式（"躲我身后""这里安全"）。弧光：从独自守一个不存在的骑士团，到找到值得挡在身前的新伙伴。
- **希尔（Seir）· 暗**：暗巷长大的孤儿神射手，讨厌欠人情。**口癖**：嘴硬 + "别误会，我只是顺手"。弧光：别扭地被佣兵团的温度融化。**登场支线**：灰环镇偷药救染病孩子。
- **萝（Rou）· 光**：神殿长大的祭司，能听见"光"的低语，温柔近乎天真，有起死回生之力。**口癖**：软、慢、把痛往自己身上揽。弧光：把曾得到的温柔加倍还给世界。
- **黛安娜（Diana）· 水**：书香门第的天才法师，冷静理性近乎冷漠，钻研魔法只为求知。**口癖**：数据/逻辑腔（"数据不会骗人"），但会在"为他人施法"时露出温度。**剧情关键**：她是**第一个破译褐尘"意志"**的人（矿洞章的脑）。
- **海莲娜（Helena）· 风**：流浪剑客，追求极致的"快"，爽朗行侠。**口癖**：痛快、挑战式（"跟得上我的剑吗"）。
- **加西亚（Garcia）· 地**：矿山出身的壮汉，沉默如山，信"站着不倒就是对同伴最好的承诺"。**口癖**：极少开口，一开口就短（"有我在，塌不了"）。
- **莉亚（Lia）· 地/风**：草原部族女猎手，开朗直率，把同伴当族人。**口癖**：明快、狩猎比喻（"我的箭从不空手而归"）。

> 注：refithea / rigenette / olstein / glacia / liatris / loen 六人**归入 S2 及后续卡池**（本作已有其美术，可作 S1 期间的限定/预热角色，但不进 S1 主线）。

### 4.3 反派（S1）
- **巨魔王（Troll King）**：被褐尘泡了千年的巨兽，盘踞诅咒山脊。硬到正面破不了防，弱点是尘没能填满的旧伤缝。第4/5章 BOSS。
- **魔王 · 巴尔（Demon Lord Bal）**：世人眼中的终极魔王，真身是封印永夜的最后一道锁齿。S1 最终 BOSS + 反转揭示者。**基调**：他不是狂徒，是守了一千年的疲惫狱卒；临终把真相与嘱托交给佣兵团。
- **涅夫提斯（Nefertis）**：永夜女皇，S1 只留阴影，S2 主敌。

### 4.4 关系网（主线索）
- **泰瑞德 = 团的心脏**：把所有人聚起来的人；对米娜亦师亦兄；与莉可莉丝拌嘴（她嫌他莽、护他护得最凶）。
- **指挥官 = 团的脑**：读懂每个人；与莉可莉丝有一条安静的信任线（营火吐露烬火镇只讲给他一个人）。
- **莉可莉丝 ↔ 米娜**：刀子嘴豆腐心的"姐姐"，嘴上嫌弃、手上护着。
- **贾丝蒂亚 ↔ 加西亚 / 奥尔斯坦（S2）**："盾"的同类，沉默的相互托付。
- **黛安娜 = 剧情引擎**：负责把"褐尘有意志""巴尔不是源头"这些谜面一层层揭开。
- **希尔 ↔ 团**：从"用完就走"到不知不觉留下。
- **恋爱/后宫线（BD2 风·轻）**：指挥官为安静的中心，数名角色对他有若隐若现的情愫，全程克制、点到为止、可选支线展开，不喧宾夺主。

## 7. 季度路线图（追番模型）
- **第一季《启程之烬》**（开服 ~12h）：本文件全部内容。结尾钩子 = 永夜将至。
- **第二季《永夜将明》**：涅夫提斯 / 永夜轮回 / "选择醒着，哪怕醒着会疼"。+ 新地区（破碎边境·永夜回廊）+ 新角色（refithea/rigenette/olstein/glacia/liatris/loen 进主线）+ 新机制。基于第二卷小说改编。
- **第三季+**：超出现有两卷的**全原创新篇**（按 §1 语感规范新写）。每季 = 一个新 cour：新章节 + 新卡池 + 新地图 + 新机制。

## 8. 落地流程（写→进游戏）
1. 每场戏按 §1 规范写成 `js/story.js` 的 beat 数组（`{bg,who,side,speaker,text,clear}`）。
2. `node scripts/build.js` → bump `ASSET_VER`+`?v` → 部署 → **Playwright 横屏**冷缓存跑一遍（跳过、进关卡看演出/立绘/名牌）。
3. **竖切推进**：一章一个竖切，改完即部署验收，不憋大版本。
