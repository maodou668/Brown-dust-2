# 剧本喂料模板（你写剧情，我接进游戏）

> 旧剧情已全部清空。这份文件是你写剧情、喂给我时的**格式说明 + 技术清单**。
> 你不用管代码——按下面的样子写台词就行，我负责翻译成游戏能跑的格式、配立绘、上线。
> 世界观和人物设定由你重写；这里只保留和游戏美术/引擎对应的**技术锚点**（角色代号、背景、敌人代号）。

---

## 一、一场戏怎么写（照这个格式给我）

一场戏 = 一串台词。每一句请标清楚三样：**谁说的、配哪张脸、背景在哪**。可以直接这样写给我：

```
【背景：森林深处】
（旁白）夜里的森林，静得能听见自己的心跳。
泰瑞德：喂，别走那么快，等等我！
米娜：（小声）前辈……我有点怕。
指挥官：站住。前面有东西。
（旁白）草丛里，一双绿色的眼睛亮了起来。
```

我拿到后会翻译成游戏里的一句句 beat。你也可以更省事，直接写成"背景 + 角色：台词"的剧本样式，我来补旁白节奏和立绘调度。

**几条约定：**
- **旁白**：不写名字、居中显示，只写"看得见的画面/发生了什么"。
- **指挥官**（玩家自己）：**只有名牌、没有立绘**（露脸的是别人）。
- **一句一行**：一句台词或一段旁白单独一行，别几句挤一起（方便我逐句配演出）。
- **表情**（可选，增强层做好后可用）：想指定某句的表情就标一下，比如"莉可莉丝（生气）：……"。现在先不标也行。

## 五、剧情"插槽"（哪些地方会自动播你写的戏）

游戏已经接好这些触发点，你写好对应内容我填进去就自动生效：

| 插槽 | 什么时候播 |
|---|---|
| **开场** | 第一次进游戏自动播（对应代号 `prologue`） |
| **关卡前剧情 ×7** | 进每个主线关卡前自动播（对应 `stage1`～`stage7`；关卡布局在 `world.js`，可增减） |
| **章节结局** | 打完某个关键关卡后播（如魔王城通关→本章终章） |
| **角色羁绊** | 在佣兵/图鉴界面点角色触发（每人一段，对应 `side_角色代号`） |
| **回放** | 看过的剧情都能在剧情菜单里回看 |

## 六、给我的最省事方式

你可以：
1. **一段一段发**：一次发一场戏（比如"开场"或"莉可莉丝羁绊"），我接一段、部署一段、你验一段。
2. **或者整章发**：写好一整章的几场戏一起发，我批量接。

你只管写"背景 + 谁说 + 说什么"，剩下的（立绘调度、旁白节奏、逐字演出、上线、自测）都我来。
