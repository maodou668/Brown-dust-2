# 剧本喂料模板（用户=编剧 · 工程=演出）

> 分工：**剧情内容（哪些场景、谁说什么话）由用户写**，贴给 Claude 即可；
> Claude 负责翻译成剧本 DSL、配演出/美术/音效、接进游戏、自测上线。**Claude 不再自创文案**。
> 写法随意，不用管格式多严——下面的标记能写就写，不写 Claude 会按内容自行安排演出并给你确认。

## 最简写法（够用）

```
【场景：夜路林道】
（旁白）烛河镇外的林道。
泰瑞德：夜路就一条规矩……
米娜（小声）：前辈，她看的那边没有路。
```

- 一句一行；旁白用（旁白）或不写名字。
- 玩家角色写「指挥官」：只有名牌，无立绘。

## 可选演出标记（想指定演出方式时用）

| 标记 | 效果 |
|---|---|
| 【场景：xxx】 | 换背景。现有实景：夜路林道 / 镇门 / 营地篝火；写个新地点 Claude 就去生成 |
| 【演出：地图】 | 这一段用小人走位演（角色在场景里真的走动/转身/头顶冒对话泡/镜头推拉） |
| 【演出：对白】 | 标准立绘对话（默认） |
| 【演出：条漫】 | 条漫分镜（写清每格画面+台词） |
| 【CG：画面描述】 | 全屏 CG + 镜头缓动（现做图充位，视频素材到位可替换） |
| 【低语】 | 低语演出（对白框只出 …………，逐字慢速+低频音效，指挥官视角不触发） |
| 【选择：A文案 / B文案】 | 玩家选择支；后续用「（选A时）xxx」「（选B时）xxx」写分支台词 |
| 【战斗：敌人描述】 | 插一场战斗；「（战斗中，敌方半血时）某某：台词」= 战中插话 |
| 角色名（动作描述）：台词 | 动作会翻成旁白拍或小人动作 |

## 交付流程

1. 你贴剧本（一幕、一章、几句都行）。
2. Claude 翻成 DSL 接进游戏 → 部署 → 给你链接和截图验收。
3. 要改直接说「第几句改成 xxx」。
