# 迭代规划 · 向《棕色尘埃 2》看齐

> 当前版本只实现了「回合制 + 抽卡 + 关卡」的玩法骨架。本文件基于对 BD2 实际设计的研究，
> 规划出分阶段、可落地的迭代路线，目标是逐步补上 BD2 真正的「精髓」。

## 一、BD2 的核心支柱（研究结论）

| 支柱 | BD2 的做法 | 我们的现状 |
| --- | --- | --- |
| **剧情叙事** | 以「Pack（章节卷）」推进主线，大量对话演出、角色支线，是口碑核心 | ❌ 完全没有 |
| **美术 / 立绘 / 演出** | 高质量 2D 立绘 + Live2D 风格动态过场（Cutscene） | ❌ 仅 emoji 占位 |
| **战斗（战术）** | 3×4 网格，**站位决定攻击目标**，技能带**击退/位移**，靠操控敌人位置取胜 | ⚠️ 有回合制但无网格/位移 |
| **服装系统（一角多服）** | 角色靠「服装」解锁，每套服装=新技能+新立绘，重复获得升 +0~+5 | ⚠️ 有角色无服装层 |
| **专属装备（EX gear）** | 每角色专属武器/装备，R/SR/UR 三档，给专属属性 | ❌ 没有装备系统 |
| **抽卡** | spark（200 点保底兑换）+ 希望之粉保底货币，多卡池 | ⚠️ 仅有 90 抽软保底 |
| **养成** | 等级 + 装备 + 专属武器 + 升星 + 突破 | ⚠️ 仅等级 |
| **玩法模式** | 主线 Pack、角色支线、活动、深渊/Boss、竞技场 | ⚠️ 仅线性关卡 |
| **运营系统** | 酒馆招募、签到、任务、商店、音频/语音 | ❌ 没有 |

## 二、关于立绘 / 美术的现实说明（重要）

作为代码智能体，我**能写出全部系统与演出逻辑**，但**无法手绘真实的动漫立绘**。因此美术分两条线推进：

1. **系统先行**：所有需要立绘的地方（剧情对话、角色档案、抽卡演出）都做成「可替换美术管线」——
   先用**程序化 SVG/CSS 风格化立绘**做高质量占位，并预留 `art` 图片字段。
2. **真实美术接入**（后续）：你可以提供真实立绘 PNG（自绘/委托/授权素材），或后续接入 AI 生图，
   我把图片放进 `assets/` 并在数据里填 `art` 字段即可自动替换占位，无需改逻辑。

> ⚠️ 注意版权：BD2 官方立绘受版权保护，不能直接搬运到公开站点。建议用原创/授权/AI 生成的素材。

## 三、分阶段迭代路线

### ✅ 阶段一：叙事演出系统（本次已动手）
- 视觉小说式**对话引擎**：全屏场景背景、左右立绘位、说话人名牌、旁白、逐字演出、点按推进、跳过。
- **序章剧情**：建立世界观、两名初始角色、魔王巴尔的威胁。
- **关卡前剧情**：每关进战斗前播放一段剧情，给战斗叙事动机。
- **风格化立绘框架** + 多套**场景背景**（森林/矿洞/山脊/魔王城/城镇）。
- 剧情「看过」记录进存档，可在设定里重看。

### 阶段二：战术战斗深化（还原 BD2 战斗手感）
- 引入 **3×4 网格**与**站位系统**：站位决定默认攻击目标。
- 技能加入**击退 / 位移 / 范围形状**（直线、十字、范围），靠把敌人推到一起再 AOE。
- 回合「预排」：先排好 5 名角色的行动顺序再执行。
- 战斗演出强化：技能动画、镜头、命中特效。

### 阶段三：养成系统
- **装备系统**：武器/防具/饰品，词条与品质（R/SR/UR）。
- **专属武器（EX 装备）**：每角色专属，提供专属属性与被动。
- **升星 +0~+5**：重复角色/服装强化技能（降 SP、加数值、加效果）。
- **突破 / 等级上限解锁**。

### 阶段四：服装系统 + 抽卡重做 + 酒馆
- **一角多服**：同一角色多套服装，每套独立技能与立绘，可切换。
- **抽卡重做**：spark 兑换 + 希望之粉保底货币 + 多卡池（服装池/装备池/常驻池）。
- **酒馆招募**：用招募券在酒馆获取角色，独立于抽卡。

### 阶段五：玩法模式扩展 + 视听
- **主线 Pack 化**：把关卡重组为「章节卷」，每卷含多节剧情+战斗。
- **角色支线、限时活动、深渊/Boss 挑战、竞技场（模拟对战）**。
- **音频系统**：BGM、音效、（可选）语音台词。
- **签到 / 任务 / 商店 / 邮件**等运营系统。

### 阶段六：美术替换与打磨
- 接入真实立绘/场景素材，替换占位。
- Live2D 风格的呼吸/摇摆动效，过场演出。
- 整体 UI 二次打磨、性能优化、移动端手感。

## 四、技术演进
- 数据资源化：角色/服装/技能/剧情/关卡拆成清晰的数据层，便于扩展与（未来）外置 JSON。
- 存档版本迁移：每次加字段做向后兼容迁移，老存档不报错。
- 模块化：`story.js`（叙事）/`battle.js`（战斗）/`gear.js`（装备）等逐步拆分。
- 可换皮美术管线：所有立绘/场景支持「图片优先，占位兜底」。
