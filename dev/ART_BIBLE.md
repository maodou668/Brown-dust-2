# 美术圣经（全游戏风格一致性标准 · v0 草案，数值待用户定稿）

> 起因（2026-07-03）：用户判定全游戏风格不统一——各资产是"各自内部一致的孤岛"（人物/UI/场景/立绘/VFX 各一套），从未做过全局对表。本文件是全局标准，**任何新资产先过这里，再过部门闸门**。

## 基准锚
**16 个人物 field sprite（锁法A）= 全游戏基准**。人物重做成本最高、验收最充分，其余一切向人物对齐。

## 五轴硬指标（stylegate 检查项）
| 轴 | 标准 | 检查方式 |
|---|---|---|
| 1. 调色板 | 全局主调色板 48+1 色（`art/_palette/master_palette.json`，抽取自 16 人物+锚点瓦片）；新资产吸附后色距≤20 | `scripts/palmap.js` 归一 + scenegate 色距 |
| 2. 饱和/明度带 | 场景资产：饱和 18–50%、明度 22–52%（人物允许 35–65% 饱和作前景强调，VFX 豁免） | `scripts/styleaudit.js` 数值 |
| 3. 描边 | 立体物深描边占比 ≥14%（不足用 `scripts/darkoutline.js` 确定性加深，2圈 k=0.26 起） | scenegate |
| 4. 像素密度 | 1m ≈ 38px（角色 64px≈1.7m）；缩小 <0.5x 禁止、放大仅整数倍 | SCENE_COMPOSITION §九 |
| 5. 相机 | 3/4 顶视轴对齐：顶面为主 + 南侧立面可见（民房比例≈顶 70%/立面 30%）；禁旋转/等距菱形/卫星平摊 | 逐件目视 + 同框图 |

## 归一工具链（存量不重画）
- `scripts/masterpal.js`：重抽主调色板（基准资产变更时）。
- `scripts/palmap.js`：保色相钳带 + 软吸附（v1 硬吸附会把干草映成土色——**保色相是底线**）；参数：satBand/vBand/snap。
- `scripts/darkoutline.js`：描边加深。`scripts/unbg.js`：basic 模式灰底去除。

## 🚦 同框闸门（硬性，跳过=返工——2026-07 两轮返工的根因就是没执行它）
**每件新资产必须**与「人物 + ≥2 件已验收资产」合成同框图（真实比例、同一草地底）发用户过目。单件好看不算数，同框不搭=打回。渲染端 mute/gloom 是最后一层，同框图先看裸值。


## 八条一致性检查（大白话版，同框合影时逐条过——2026-07 用户定为管线闸门）
1. **颜色**：全游戏一份色卡，不许太艳、太亮、太黑（机器查）。
2. **角度**：全游戏一台相机，斜上方往下看；露屋顶+一点正面（机器查不了旋转，目视）。
3. **大小**：按真实世界比例，信箱不许跟房子一边大（比例表查）。
4. **像素颗粒**：马赛克格子必须一样大，不许硬放大缩小（规则查）。
5. **勾线**：每个东西一圈深描边（机器查，可自动加深）。
6. **光照**：全部"阴天柔光"，不许谁单独带大太阳浓影（目视）。
7. **细腻度**：笔触精细程度一致，不许一个精雕一个简笔（目视）。
8. **胖瘦造型**：同一种敦实卡通体型感（目视）。
> 6/7/8 机器量不了 → 靠**同框合影**兜底：新资产必须与小人+已验收资产合影发用户，合影不搭=打回。

## 流程
生成（提示词带风格契约）→ palmap 归一 → stylegate 五轴 → 同框图 → 用户点头 → 接入。
