# 场景设定书 · 烛河村（第一章「空屋」主舞台）

> 依据：第一章剧本（委托书十一个红手印 / 磨坊的叔叔 / 全村凑三十七银 / "出磨坊的时候，全村人都等在坡下" / 序章的磨坊桥与溪）。
> 用途：先定"这是哪、有什么"，投资人确认后才进入选材与摆放。**本文档是摆放的唯一上游依据。**

## 一、这是哪（剧情定位）
烛河村：烛河下游的贫穷小村，**十一户人家**，靠磨坊和几块薄田过活。委托人是全村（十一个红手印按在同一张委托书上），委托内容是"看看磨坊的叔叔"。表面上是个温吞正常的村子——鸡在刨食、烟囱冒烟、酸菜味——实际全村在共同守一个秘密。**白天进村的观感必须"活而正常"，違和感只允许从细节漏出来**（坟场太新、磨坊窗户全钉死、村民都不看磨坊方向）。

## 二、场景元素清单（剧情反推）
### 地形骨架
- **溪流**：从北向南穿过场景东侧（序章"磨坊桥"所在）。⚠️ 资产缺口：水面瓦片（水↔草过渡）。
- **坡**：磨坊立在溪东的**高坡**上（剧情："全村人都等在坡下"）——坡下是村子，坡上只有磨坊，一条坡道相连。⚠️ 资产缺口：坡沿/台阶表现（可用悬崖沿瓦片或阴影+之字坡道路径先凑）。
- **村域**：溪西平地，两排宅基地夹一条主路（现有 v5 布局骨架保留）。

### 植被与地面
- **树**：村外橡树林缘带（四缘）；坟场专用枯树；村长家院角一棵果树。⚠️ 溪边按理该有垂柳——远期补，先用橡树。
- **地面材质分区**（样式板选定后套用）：主路+坡道=土路；**广场=石板**（全村唯一"体面"的地方，衬村长家）；宅间小径=碎石；农家院坝=踩实的土；田=垄泥；其余=草地。

## 三、入场走线（玩家视角，从进村到磨坊）
1. **从西边主路进村**（序章方向延续）。第一眼：**村栅门**虚掩，门柱挂一盏白天不点的灯笼；栅门框住的远景正好是磨坊的风车叶（构图钩子——目的地一进村就看得见，但隔着整个村子和一条溪）。
2. **过栅门直走**：主路两侧渐次出现民房；左手（北）第一栋是石屋，右手（南）是牧栏和农田——先看到"生计"，再看到"人家"，村子有呼吸感。
3. **走到村中**：路面从土路变石板——**广场**。井在正中，公告板/烛龛在角上，村长家的大宅正对广场北侧（进村动线的第一个"戏眼"，村长在这接玩家）。
4. **广场往东**：石板重新变回土路，路过木屋B和更密的民房（民房D/E/F 补位处），右手南边是贫户院坝+鸡圈——越靠东越穷，铺"磨坊边缘户"的叙事梯度。
5. **到溪边**：**磨坊桥**（序章战斗发生地，玩家会认出来）。过桥即坡下——**抬头看坡上的磨坊**：全村最高、最旧、窗户钉死的建筑，逆着光。坡道之字形上坡，坡下有一小片空地（尾声"十一个人站得整整齐齐"就站这）。
6. **死角设计**：村北后巷尽头是**坟场**（枯树+围栏），不在主动线上、但从主路能瞥见一角——好奇的玩家拐过去会发现"墓碑数量不对劲"（第一章伏笔）。村南林缘留一条窄口，通向后续章节的营地（暂时封闭）。
7. **无地下层**（第一章不设地下；磨坊内部/二楼是独立室内场景，另立设定书）。

## 四、氛围
- 时段：灰蒙蒙的上午（剧本原文）。光柔、影淡、暗角轻（vignette≤0.26）。
- 活气：两处烟囱烟（村长家+贫户屋）、鸡、风吹落叶；广场可站 2-3 个村民 NPC（都不看磨坊方向——细节違和感）。
