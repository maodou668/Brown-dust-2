# 棕色尘埃 · 烬火行纪 — 美术圣经（Art Bible）

> 本文件是全游戏视觉的最高规范。**任何美术资产，不符合本规范即不入库。**
> 目的只有一个：让 16 个角色、10 个怪物、7 张场景、上百个 UI 元素，看起来像出自**同一双手、同一个世界**——
> 而不是一堆风格漂移、撞色糊边的"拼多多素材"。

---

## 0. 一句话愿景

> **暗色奇幻 × 动漫像素风：在褐尘与永夜里，燃烧着的一团暖火。**

整部游戏的情绪，建立在一组对比上：
- **冷／暗／褐** = 世界（褐尘、永夜、魔物、压抑）
- **暖／亮／彩** = 希望（角色、火光、圣光、黎明）

凡是画面，都要服务这组对比。失去对比，就失去了《烬火行纪》的灵魂。

---

## 1. 四条美术支柱（Pillars）

1. **暗调底色，暖光焦点**
   背景永远压暗、偏冷、带褐尘；视觉焦点（角色、火、光、关键道具）用暖光提亮。一张图里，最亮最暖的地方，就是情绪所在。

2. **动漫骨，像素肉**
   角色是动漫比例与神态（约 1:5.5～6 头身，非 Q 版、非写实），用**现代干净的像素风**呈现（接近 HD-2D，而非复古 8-bit）。要"精致的像素"，不要"怀旧的马赛克"。

3. **褐尘是世界的母题**
   "褐色尘埃"是这个 IP 的视觉签名。被侵蚀的一切——魔物的边缘、腐坏的矿石、沉睡的村庄——都向**褐尘色**褪色、风化。褐尘必须在每一个被腐蚀的画面里出现。

4. **克制而精致**
   有限调色板、干净描边、可辨剪影。**廉价感的来源是：杂乱、撞色、糊边、比例失调、风格漂移。** 我们用"少而准"对抗它。

> **风格参照（描述性目标，非抄袭）**：Octopath/HD-2D 的光影层次、Brown Dust 2 的角色优雅、Sea of Stars 的场景丰富、Loop Hero 的暗调克制。

---

## 2. 技术规范（Technical Specs）

**统一像素密度**：所有资产共用**同一像素颗粒度**——这是"像一个游戏"的物理基础。绝不混分辨率。

| 资产类型 | 画布尺寸 | 背景 | 视角 |
|---|---|---|---|
| 角色立绘 / 战斗精灵 | 128×128 | 透明 | 正面略 3/4，面向镜头 |
| BOSS | 200×200 | 透明 | 正面，强剪影 |
| 普通怪物 | 128×128 | 透明 | 正面/侧 3/4 |
| 场景背景 | 256×384（2:3 竖屏） | 不透明 | 平视，景深分层 |
| 资源/UI 图标 | 32×32 | 透明 | 正面 |
| 元素/职业小图标 | 24×24 | 透明 | 正面 |
| 世界地图瓦片 | 32×32 | 视情况 | 俯视（top-down） |

**统一渲染规则**：
- **描边**：外轮廓 = 统一深色描边（`single color black outline`，实为深紫黑而非纯黑）；内部线条克制、选择性。
- **光源**：**全游戏统一——上方偏左的暖光**。所有阴影朝右下。
- **明暗阶数**：2～3 阶柔和过渡。**不用纯黑阴影、不用纯白高光**（见 §3）。
- **抖动（dithering）**：仅用于背景的大面积渐变，角色/图标禁用。
- **透明**：角色/怪物/图标透明底；场景不透明。

## 4. 角色设计规范

- **比例**：约 1:5.5～6 头身的动漫体型。**非 Q 版、非写实。**
- **构图**：站立全身，正面略偏 3/4，面向并略微俯视镜头（亲和感）。
- **剪影先行**：闭眼也能从轮廓（发型 / 武器 / 装束）认出是谁。
- **主色 = 元素色**：每个角色的整体色调取自其元素（见下表 `color`），再以中性色与点缀色平衡。
- **神态贴合性格**：立绘表情必须传达人设（高傲 / 怯生 / 沉静 / 爽朗）。

### 服装变体（一角多服）
同角色多套服装，**脸型/发型基本特征必须保持一致**，只换装束与配色基调。技术上用同一 `seed` 家族 + 换装工具（transfer-outfit / character-state），避免"换套衣服变了个人"。

## 5. 怪物 / BOSS 规范

- **普通魔物**：冷暗调，**边缘带褐尘侵蚀感**，眼神空洞（被永夜操纵）。
- **BOSS** 用更大画布、更强剪影、专属色：
  - **魔王巴尔**：暗紫黑 + 血红 `#8a1a3a`，疲惫而威严（他是守门的狱卒，不是纯粹的恶）。
  - **巨魔王**：大地褐绿，被褐尘泡了千年的厚重质感。
  - **暗影女皇 涅夫提斯**：**关键——不要画成怪物脸**。她是温柔疲惫的暗紫色调，带"摇篮曲"般的柔光，**美而哀**。她的慈悲与悲剧，必须从画面里看得出来。
- 敌人同样遵守元素配色编码。

## 6. 场景 / 背景规范

每个场景一句情绪 + 主色，景深分三层（前景剪影 / 中景主体 / 远景雾），**中心略空，给立绘与 UI 留位**。

| 场景 | 情绪 | 主色 |
|---|---|---|
| 艾尔玛森林 | 幽静、薄雾 | 幽蓝绿（已出样 ✅） |
| 森林深处 | 更冷更暗，褐尘渐多 | 冷蓝绿 + 褐尘 |
| 废弃矿洞 | 暗褐，火光点缀，褐尘"活着" | 暖橙点缀的暗褐 |
| 诅咒山脊 | 狂风冷峻 | 青灰风雪 |
| 魔王城 | 凝固的夜 | 暗紫 + 血红 |
| 城镇 | 唯一的暖色避风港 | 暖橙 |
| 永夜 / 虚空 | 化不开的黑，摇篮曲 | 灰黑 + 褐尘飘 |

**褐尘母题**：被侵蚀场景的空气里要有褐尘颗粒（与游戏内 `bfx` 粒子呼应）。**暖光焦点**：每张图留一处暖光（火光 / 一束光 / 黎明）制造希望。

## 7. UI 规范

- **框 / 卡**：暗紫面板 `#261d33`，1px 半透明白描边，圆角；稀有度用边框色 + 角标。
- **按钮**：主操作 = `#b06bff→#ff6b9d` 紫粉渐变；金色按钮 = 重要操作（招募 / 升级）。
- **图标**：统一 32px 像素图标，深描边，透明底，**同一光源**。逐步用像素图标替换 emoji（🪙→金币、💎→宝石、职业/元素图标）。
- **不用纯黑纯白**：UI 暗部用夜紫，高光用暖白 `#ece6f5`。
- **Logo**：为 "棕色尘埃 / BD" 做一个像素徽标（金 + 暗紫 + 一点火光）。
- **字体**：中文用系统无衬线（像素中文字库不现实）；数字 / 标题可加像素描边点缀，保持调性。

## 8. 反"拼多多" Do / Don't 清单

**DON'T（廉价感来源）**
- ❌ 撞色、霓虹乱闪、饱和度失控
- ❌ 糊边、AI 噪点、细节脏乱
- ❌ 比例忽大忽小、混分辨率
- ❌ 纯黑描边配纯白高光
- ❌ 每张图风格漂移、光源乱打
- ❌ 背景太满、不给 UI/立绘留白

**DO（精致感来源）**
- ✅ 锁母版调色板（`color_image`）
- ✅ 固定风格参数、尺寸、像素密度
- ✅ 统一上方暖光光源
- ✅ 剪影先行、比例统一
- ✅ 暖冷对比讲情绪
- ✅ 褐尘母题贯穿
- ✅ 留白给 UI 与立绘

## 9. PixelLab 生产参数（把圣经变成可执行）

**统一 prompt 模板**：
```
anime fantasy pixel art, {主体描述}, {元素色 accent}, clean dark outline,
soft directional lighting from upper-left, limited palette, dark fantasy mood, high quality
```

**固定生成参数**（写进 gen 脚本，全局统一）：
- `outline = "single color black outline"`
- `shading = "medium shading"`
- `detail  = "medium detail"`
- `text_guidance_scale = 7.5`
- `color_image = assets/style/master_palette.png`（**强制母版调色板**）
- `no_background = true`（角色/怪物/图标）｜ `false`（场景）
- 尺寸：见 §2 表
- `seed`：角色用固定 seed 段，便于一致地重生成

**风格锚定**：选定 1～2 张定稿（如莉可莉丝）作为 **BitForge 参考图**，后续角色以它为风格基准，进一步压住漂移。

## 10. 单图验收清单（每张过审标准）

- [ ] 只用了母版调色板的颜色
- [ ] 尺寸 / 像素密度符合 §2
- [ ] 描边 / 光源 / 阴影阶数统一（上方暖光、非纯黑白）
- [ ] 剪影可辨、比例正确（1:5.5～6 头身）
- [ ] 元素色 / 稀有度配色正确
- [ ] 透明 / 不透明正确
- [ ] 褐尘母题（侵蚀类资产）已体现
- [ ] **与已定稿资产并排，看不出风格漂移**

> 最后一条是总检验：把新图和已定稿的图摆在一起，如果一眼能看出"这张不是一套的"，就重做。
